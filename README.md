# Homebrew tap

```sh
brew install looptender/tap/keepgoing
```

Installs [looptender](https://github.com/looptender/looptender), which keeps long-running coding-agent loops going. The released v0.2.0 executable is still named `keepgoing`. The formula installs the prebuilt release binaries for macOS and Linux and checks them against the release's published SHA-256 checksums.
